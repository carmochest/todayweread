# Today We Read — storefront prototype

Clickable design prototype for the Today We Read online bookshop (to be built as a Shopify theme).

- `index.html` — all pages (home/about, books, non-books, events, gift card, account, checkout), hash-routed
- `app.js` — placeholder catalogue, cart/wishlist logic, and the animated book-butterfly
- `butterfly-snippet.html` — reusable flapping-butterfly markup + CSS
- `fonts/` — ABC Grow (trial) and PP Mori

Open `index.html` in a browser, or view the GitHub Pages deployment.
